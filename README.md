# 个人投资者股票决策辅助 Agent｜永久记忆版 V6.0

这是一个面向 A股、美股和港股的教学研究原型。V6.0 在冻结 V5.8 原分析逻辑的前提下，新增邮箱账号、跨设备永久保存、完整分析快照以及会话内首次买入／加仓记录。

## V6.0 新增能力

- 邮箱注册和密码登录；同一账号可在不同联网设备恢复数据。
- 风险测评、未完成问卷草稿永久保存。
- 每只股票建立独立会话，永久保存会话消息和历次完整分析结果。
- 再次打开某只股票会话时，默认恢复第一次分析的完整页面；也可切换查看之后的分析版本。
- 已买入股票可在会话内登记“首次买入／加仓”：
  - 按实际支付人民币总额填写；或
  - 按股数、成交单价、交易费用及汇率填写，由系统自动计算人民币投入本金。
- 组合持仓占比只读取当前账号中仍保留的股票会话本金。
- 删除整个股票会话在业务上等价于该股票已全部卖出，并从组合统计中永久剔除。

## 保持不变的原功能

- A股、美股、港股真实公开行情。
- 统一使用最近五年数据；上市不足五年时使用全部可得数据并降低置信度。
- 分页风险问卷、用户风险等级、股票风险等级、个人适配、风险预算。
- 历史相似状态检索、多周期分析、持有／复核周期。
- 已持有股票检查和卖出信号。
- 百分数和价格统一显示到小数点后三位。

核心分析文件 `agent_core.py` 和风险问卷文件 `questionnaire.py` 与 V5.8 基线保持一致。

## 数据保存与安全

- 云端数据库使用 Supabase。
- 网页仅使用 `Project URL` 和 `Publishable key`。
- 数据库已开启 Row Level Security；每个登录用户只能读写自己的资料。
- 不要使用 `secret key` 或 `service_role key`，也不要把真实密钥上传到 GitHub。
- 密码由 Supabase Auth 处理，本应用数据库不保存明文密码。

## 第一次部署

请按 [GitHub部署说明.md](GitHub部署说明.md) 操作。核心步骤只有三部分：

1. 将本文件夹中的程序文件上传到原 GitHub 仓库。
2. 在 Supabase SQL Editor 中完整运行一次 `一键建表_V6.0.sql`。
3. 在 Streamlit Community Cloud 的 App settings → Secrets 中填写两个配置项。

## 本地运行（可选）

```bash
python -m pip install --upgrade -r requirements.txt
streamlit run app.py
```

本地运行时，把真实配置放到 `.streamlit/secrets.toml`；该文件已被 `.gitignore` 排除。
