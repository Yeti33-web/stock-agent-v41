# V6.2 加仓适配分析版更新清单

## 本次新增能力

1. 已经登记实际持仓的股票会话新增独立入口“加仓适配分析”。
2. 支持按计划人民币金额，或按计划股数、预计成交价、预计费用和汇率录入加仓方案。
3. 每次测算自动刷新股票最新公开行情，并统一使用近五年或上市以来全部可得数据。
4. 复用原模型的个人适配、持有周期、时点评分和单股风险预算，不另造一套互相矛盾的评分。
5. 在原分析结果上新增现有仓位、加仓后风险敞口、会话组合集中度和卖出信号冲突检查。
6. 形成三档结论：
   - 可在风险预算内小额分批加仓；
   - 满足条件后再考虑加仓；
   - 当前暂不适合加仓。
7. 明确展示支持因素、需要满足的条件、当前限制和停止加仓／重新复核信号。
8. 每次加仓适配分析永久保存到对应股票会话，可跨设备再次查看。
9. 所有价格、金额和百分数继续统一显示到小数点后三位。

## 计划分析与真实持仓隔离

- 运行“加仓适配分析”只保存计划及判断，不写入真实买入交易。
- 测算完成后，累计本金、股数和组合占比保持不变。
- 只有用户真实成交后，主动进入原“首次买入／加仓”页面登记，才会更新持仓。
- 测算失败时不保存半成品，也不会影响任何已有持仓数据。

## 原功能冻结说明

本次没有修改：

- `agent_core.py` 的股票分析、相似周期、持有周期、风险适配、仓位预算和卖出信号规则；
- `questionnaire.py` 的14题风险问卷和用户画像规则；
- `cloud_store.py`、`session_memory.py`、`snapshot_codec.py` 的永久保存逻辑；
- Supabase 数据表、用户隔离权限和邮箱验证码登录；
- A股、美股、港股行情获取与五年数据窗口。

V6.2 仅修改页面接入文件 `app.py`，并新增独立模块 `add_position_analysis.py`。

## 升级方式

已经正常运行 V6.1 时，只需在 GitHub 上传：

1. `app.py`（覆盖旧文件）；
2. `add_position_analysis.py`（新增文件）。

不需要重新运行 SQL，不需要修改 Streamlit Secrets，也不需要重新配置验证码邮件或 SMTP；已有账号和数据会继续保留。
