# V6.5 版本更新清单

## 更新目标

根据历史时点复现中发现的偏差，减少方向证据不足时的过度确定结论。V6.4已完整保留为旧版备份，V6.5不会自动改写用户已保存的历史快照。

## 正式逻辑变更

- 合并重复趋势计分。
- 动量和相对强弱改为波动率标准化。
- 成交量与相似周期不再进入正式方向分。
- 降低宏观与基本面的方向权重；基本面不参与20日及以下方向分。
- 新增固定规则的历史验证闸门，分为通过、有限通过、未通过。
- 持有期改为优先由资金时间、用户目标与执行能力确定，不再追逐当前最高分。
- 将行情方向、用户适配、股票风险明确分开展示。
- 历史验证未通过时，仓位上限为0，加仓模块也会阻断。

## 未变更的内容

- A股、美股、港股查询范围。
- 14题风险测评、账户、永久会话和持仓记录。
- 卖出信号、资讯展示、数据证据与因子字典。
- 独立历史时点复现工具仍与正式页面分开，且不读取T日之后的数据。
- 不连接券商，不自动交易，不保证收益。
