# 个人投资者股票决策辅助 Agent｜融合校准与严格认证版 V6.7

这是一个面向 A股、美股和港股个人投资者的学习研究项目。系统结合公开行情、个人风险画像、股票风险、基本面、市场环境、资讯和持仓情况，输出风险适配、持有／复核周期、观察分、仓位约束、卖出信号和加仓条件。

> 结果仅供学习与研究，不构成投资建议，不连接券商，也不执行交易。

## V6.7 新增：四个基本面因子

在保持 V6.6 严格认证原则的前提下，V6.7 为“基本面评分”新增 4 个可审计因子，作为中长期解释性辅助（只对 60／120／250 日持有期作有限修正，最多±4分）：

| 因子 | 作用 | A股（BaoStock） | 美股SEC | 美股／港股（yfinance） |
| --- | --- | --- | --- | --- |
| 投入资本回报率ROIC | ≥15%:+6；8—15%:+3；<0:-10 | 净资产收益率÷权益乘数（ROA口径近似） | NOPAT÷（股东权益＋长期负债－现金） | returnOnInvestedCapital |
| 自由现金流收益率 | ≥5%:+6；0—5%:+2；<0:-8 | 免费数据源无资本支出，暂不计算 | 经营现金流－资本支出，再÷市值 | freeCashflow÷市值 |
| 毛利率／营业利润率趋势 | 毛利率≥40%:+3；20—40%:+2；<0:-6；营业利润率≥20%:+2；5—20%:+1；<0:-5；改善+3、恶化-3 | 毛利率（营业利润率无源） | GrossProfit与OperatingIncomeLoss | grossMargins与operatingMargins |
| 估值历史分位 | 当前PE在自身近5年分位≤25%:+3；25—50%:+2；75—90%:-3；>90%:-6；亏损-7 | 历史peTTM日序列 | 暂无同口径历史序列 | 暂无同口径历史序列 |

新增因子全部遵循无前视与缺失即0分规则：财务数据只用最近公开口径；A股不提供资本支出时 FCF 不参与评分，绝不伪造。因子字典由 91 项扩展为 **95 项**。

> **V6.7.1 校准**：经 8 个“股票×历史时点”样本回测，基本面分与后续收益的秩相关为负（2024—2025 市场风格下“优质白马”被杀估值，即价值陷阱）。因此正向加分在上表已下调（负值风险惩罚保留），并把基本面定位为**质量与风险评价、不作方向信号**。详见 [版本更新清单_V6.7.md](版本更新清单_V6.7.md)。

## V6.6最重要的结论

本次对两个V6.5版本进行了逐文件比较和真实历史时点检验：

- 以“因子校准与信号分离版”为主线：保留重复因子合并、波动率标准化、方向与适配分离、成交量和相似周期不直接加分等安全设计。
- 从“因子校准与自校准版”吸收局部分数校准思路，但只允许维持、降低或阻断信号，不能把失败信号反转。
- 20日短期均值回归保留为小权重研究因子；52周位置、量价确认和波动率分位只作背景，不重复计分。
- 新增跨股票样本外认证：某周期只有在开发样本、较晚时段和至少两批不同股票留出样本中都稳定，才允许输出未来方向。
- 最终封闭检验中，没有任何周期稳定通过全部要求。因此V6.6仍展示观察分和趋势状态，但当前不把任何周期解释为已验证的未来涨跌或买入方向。

这不是“没有算出答案”，而是模型发现现有证据不足后主动拒绝过度判断。详细结果见 [因子融合与封闭检验说明_V6.6.md](因子融合与封闭检验说明_V6.6.md)。

## Agent A与Agent B

| 程序 | 用途 | 数据范围 | 是否修改模型 |
| --- | --- | --- | --- |
| Agent A：本文件夹 `app.py` | 正式股票决策辅助页面 | 当前可得公开数据 | 只在发布新版本时人工修改 |
| Agent B：`B_历史回测Agent_V6.7/` | 独立历史时点复现（独立文件夹交付） | 只允许日期T及以前的数据 | 不修改、不训练、不保存自己的评分逻辑 |

A 与 B 已拆分为两个独立文件夹，便于分别上传部署。Agent B 内置 A 的引擎副本
（`app.py`/`agent_core.py` 等 9 个文件），每次运行直接载入副本并校验 A 的版本号、
规则编号和核心文件哈希；A 更新后用 `B_历史回测Agent_V6.7/sync_engine.py` 同步即可，
B 会自动使用 A 的最新推演逻辑。

## 主要功能

- 14题个人风险测评，形成C1—C5用户风险等级；
- A股、美股和港股最近五年或上市以来公开日线；
- 股票波动、回撤、下行波动和Beta风险等级；
- 按用户目标、用款时间和执行条件选择持有／复核周期；
- 基本面、市场环境和最新公开资讯辅助分析；
- 历史相似状态展示，但不直接修改方向分；
- 个人适配、风险预算、卖出信号和加仓条件；
- 每只股票独立会话及Supabase永久保存；
- 因子贡献、公式、权重、缺失处理和无前视历史检验；
- 独立Agent B复现历史日期T，不读取T之后行情。

## 防止未来数据泄露

Agent B执行历史日期T时：

1. 非交易日自动采用T之前最近一个交易日；
2. 行情接口只请求T及以前约五年；
3. 进入Agent前再次删除并检查T之后的所有行；
4. “今天”只在独立测试进程中临时冻结为T；
5. 财务、宏观和资讯只有实际披露时间不晚于T才可参与；
6. 免费数据源无法证明披露时间时，该证据记为缺失，不使用今天的数据倒填；
7. B输出A当时的完整页面和判断，到此结束，不读取未来H日结果。

## 部署

详细步骤见 [GitHub部署说明_V6.6.md](GitHub部署说明_V6.6.md)。本地启动：

```bash
python -m pip install --upgrade -r requirements.txt

```

## 模型边界

- 观察分不是上涨概率；
- 历史相似状态不代表未来会重复；
- 风险适配只说明用户是否可能承受风险，不代表股票会上涨；
- 当前封闭检验未认证任何未来方向，页面不会为获得结论而强行预测；
- 若以后增加方向模型，必须使用新的、未参与调整的股票和时间段再次验证。

该分析结果仅供参考，本模型仅用于学习与研究。
