# V6.7 版本更新清单

## 本次改动

在 V6.6（融合校准与严格认证）基础上，为“基本面评分”新增 4 个可审计因子，用于中长期解释性辅助：

1. **投入资本回报率（ROIC）**
   - ≥15%:+9；8%—15%:+4；<0:-10
   - A股：净资产收益率÷权益乘数（ROA口径近似，BaoStock无投入资本明细时采用）
   - 美股SEC：NOPAT÷（股东权益＋长期负债－现金）
   - 美股／港股yfinance：returnOnInvestedCapital
2. **自由现金流收益率（FCF÷总市值）**
   - ≥5%:+8；0—5%:+3；<0:-8
   - 美股SEC：经营现金流－资本支出；yfinance：freeCashflow
   - A股免费数据源未提供资本支出明细，本项不参与，绝不伪造
3. **毛利率／营业利润率趋势**
   - 毛利率≥40%:+4；20%—40%:+2；<0:-6
   - 营业利润率≥20%:+3；5%—20%:+2；<0:-5
   - 两者近期改善+3、恶化-3
   - A股：BaoStock毛利率（营业利润率无源）；美股SEC：GrossProfit与OperatingIncomeLoss；yfinance：grossMargins与operatingMargins
4. **估值历史分位（当前PE在自身近5年历史中的分位）**
   - ≤25%:+6；25%—50%:+3；75%—90%:-3；>90%:-6；亏损≤0:-7
   - A股：BaoStock历史peTTM日序列；美股／港股暂无同口径历史序列时不参与

## 定位与边界

- 新增因子属于“基本面评分”模块，只对 60／120／250 日持有期作有限修正（权重0.06／0.10／0.12，最多±4分），不构成短线方向信号；
- 缺失即0分，不伪造；无前视：财务数据只用最近公开口径；
- 因子字典由 91 项扩展为 **95 项**（基本面评分 7→11 项）；
- 未改变 V6.6 的严格认证结论：仍无任何周期通过跨股票样本外认证，页面不把观察分解释为已验证的未来涨跌。

# V6.7.1 校准补丁

## 一、历史时点财务快照接入（回测不再屏蔽基本面）

V6.6 的历史回测工具 B 在历史时点 T 会无条件屏蔽财务数据（“历史时点财务快照未接入”），
导致新增基本面因子在回测中全部失效。实测 BaoStock 财报接口返回**披露日 pubDate**，
因此 V6.7.1 改为：

- 只使用**披露日 ≤ T** 的最近报告期（如 2024-01-02 时使用 2023Q3，而非更晚披露的2023年报）；
- 估值历史分位只用 **T 及以前**的 peTTM 日序列计算，杜绝前视；
- 美股／港股免费数据源无统一可核验披露时间，历史时点仍按缺失处理（不参与）。

## 二、新增因子分值下调（价值陷阱校准）

用 8 个“股票×历史时点”样本回测后发现：基本面分与后续 60/120/250 日收益的秩相关
**为负**（约-0.7～-0.9）。原因是 2024—2025 年市场风格下，财务最优质的“白马”
（如白酒）被持续杀估值，而低估值高股息／资源股上涨——基本面高分与股价走强反向。

因此对新增因子的**正向加分下调**（负值风险惩罚保留）：

| 因子 | 原规则 | 现规则 |
|---|---|---|
| ROIC | ≥15%:+9；8%—15%:+4 | ≥15%:+6；8%—15%:+3 |
| 自由现金流收益率 | ≥5%:+8；0—5%:+3 | ≥5%:+6；0—5%:+2 |
| 毛利率 | ≥40%:+4；20%—40%:+2 | ≥40%:+3；20%—40%:+2 |
| 营业利润率 | ≥20%:+3；5%—20%:+2 | ≥20%:+2；5%—20%:+1 |
| 估值历史分位 | ≤25%:+6；25%—50%:+3 | ≤25%:+3；25%—50%:+2 |

- 负值惩罚（ROIC<0:-10、FCF<0:-8、毛利率<0:-6、营业利润率<0:-5、>90%分位:-6等）不变；
- 利润率趋势（改善+3／恶化-3）是边际信息，保留原幅度。

## 三、结论（诚实边界）

- 基本面分反映**财务质量与风险**，不预测短期股价方向；模型已在输出中注明
  “高质量股票在部分市场风格下可能跑输（价值陷阱），不把高质量当作上涨信号”。
- 新增 4 因子在回测中的定位是**中长期解释性辅助与风险提示**，方向信号仍由 V6.6 严格认证
  的价量因子决定；当前仍无周期通过样本外认证，因此页面不把观察分解释为已验证的未来涨跌。
