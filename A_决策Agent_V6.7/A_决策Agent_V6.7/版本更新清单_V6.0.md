# V6.0 永久记忆版更新清单

## 本次新增

1. 邮箱注册、密码登录和跨设备数据恢复。
2. 风险问卷资料及草稿按账号永久保存。
3. 股票会话、消息和组合本金按账号永久保存。
4. 每次分析保存独立完整快照；默认恢复第一次分析，旧快照不被覆盖。
5. 会话内新增首次买入／加仓，支持人民币总额或股数 × 单价 × 汇率 + 费用两种口径。
6. 自动更新累计本金、可得股数、平均成本及会话组合持仓占比。
7. 误录买入记录可二次确认撤销。
8. 删除股票会话仍等价于全部卖出，并级联剔除该股票的永久记录。
9. 数据库启用用户级 Row Level Security；网页不使用管理密钥。

## 原功能冻结说明

`agent_core.py` 与 `questionnaire.py` 保持 V5.8 基线文件哈希不变。A股、美股、港股行情、五年窗口、风险判断、相似周期、持有周期、仓位预算、已持有检查和卖出信号的业务逻辑未修改。

## 验证重点

- 两个邮箱账号之间的数据完全隔离。
- 同一邮箱跨设备登录后可以恢复资料。
- 点击股票会话默认显示第一次完整分析。
- 再分析只新增快照，不覆盖历史。
- 首次买入、加仓、误录撤销、会话删除均能正确重算组合本金和占比。
- 价格与百分数显示至小数点后三位。
