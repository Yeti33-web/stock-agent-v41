# V6.1 邮箱验证码注册版更新清单

## 本次仅新增／调整

1. 首次注册改为“发送邮箱验证码 → 在原网页输入验证码 → 完成注册”。
2. 注册验证不再要求用户打开邮件中的外部确认网址。
3. 验证成功后自动登录；以后仍使用邮箱和密码登录。
4. 验证码页面支持60秒倒计时、重新发送和修改邮箱。
5. 已经创建但尚未验证的账号，可通过“继续未完成注册”获取新验证码。
6. 增加常见限流、验证码错误和过期提示。

## 原功能冻结说明

本次没有修改 `agent_core.py`、`questionnaire.py`、数据库表结构和股票业务规则。A股、美股、港股行情、五年数据窗口、风险测评、相似周期、持有周期、仓位预算、卖出信号、股票会话、分析快照、持仓本金和加仓记录均保持 V6.0 原样。

## 部署注意

- GitHub 只需覆盖上传新版 `app.py`、`cloud_store.py`，其他已有程序文件不必修改。
- 不需要重新运行 SQL 建表脚本。
- 必须在 Supabase 的 **Authentication → Email Templates → Confirm signup** 中，把邮件正文改为显示 `{{ .Token }}`；可直接使用本包中的 `Supabase注册验证码邮件模板.html`。
- Supabase 内置邮件服务的发送限额仍然存在。开放给多人注册前应配置自定义 SMTP。
