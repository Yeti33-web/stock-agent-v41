# V6.7.2 版本更新清单（行业标准化）

## 本次改动

在 V6.7.1（历史时点财务快照 + 价值陷阱校准）基础上，回应“净利率与负债率行业标准化、
PE 考虑比较对象”的需求：

1. **净利率（行业标准化）**
   - 不再只用绝对阈值，优先与**同行业净利率中位数**比较：
     - 个股净利率 ÷ 行业中位数 ≥1.3 → +8；≥1.0 → +4；≥0.6 → -1；<0.6 → -6
     - 净利率为负 → -10（绝对风险优先）
   - 无行业基准时回退绝对阈值（≥15%:+8；5%—15%:+3；<0:-10）
2. **资产负债率（行业标准化）**
   - 优先与**同行业负债率中位数**比较（银行、地产等天然高负债行业自动适应）：
     - 负债率 ÷ 行业中位数 ≤0.6 → +6；≤0.9 → +2；≤1.3 → -1；>1.3 → -6
     - 绝对水平 ≥95% 额外 -4（偿债风险）
   - 无行业基准时回退绝对阈值（≥75%:-10；55%—75%:-4；≤35%:+4）
3. **PE 考虑比较对象（相对同行业中位数）**
   - 新增独立因子，与“估值历史分位”（自身纵向）互补：
     - 个股 PE ÷ 行业 PE 中位数 <0.7 → +4；<1.0 → +2；<1.5 → -1；≥1.5 → -4
   - 低于同行 = 横向低估，高于同行 = 横向高估
