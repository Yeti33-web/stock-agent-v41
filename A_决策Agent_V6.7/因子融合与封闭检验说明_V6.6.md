# V6.6 因子融合与封闭检验说明

## 结论先行

两个V6.5版本已经融合，但最终封闭检验没有支持“现有模型可以稳定预测未来涨跌”。V6.6因此保留风险、适配、周期、观察分和因子解释，并阻断所有尚未完成跨股票认证的方向结论。

这份结果不代表模型没有价值。它说明当前较可靠的能力是风险测量、个人适配、仓位约束和历史证据整理；未来方向仍属于研究信号，不能包装成已验证的买入判断。

## 两个版本如何取舍

| 内容 | 信号分离版 | 自校准版 | V6.6处理 |
| --- | --- | --- | --- |
| 价格／快均线与快／慢均线 | 合并为一个趋势块 | 分开计分，信息重复 | 保留合并趋势块 |
| 动量与相对收益 | 按近期波动标准化 | 固定倍数映射 | 保留波动标准化 |
| 成交量 | 只作背景 | 可直接加减分 | 权重固定为0 |
| 相似周期 | 只展示 | 可影响正式分 | 权重固定为0 |
| 周期选择 | 按用户目标和资金期限 | 容易受当前最高分影响 | 保留用户先验选择 |
| 20日短期反转 | 无 | 有 | 小权重研究因子，仅20日生效 |
| 52周位置 | 无 | 有 | 样本外不稳定，只展示 |
| 10日量价确认 | 无 | 有 | 样本外不稳定，只展示 |
| 波动率分位 | 无 | 有 | 作为风险提示，不判断方向 |
| 局部分数校准 | 无 | 可反转或支持方向 | 只允许维持、减半或阻断，不能反转 |
| 跨股票认证 | 无 | 无 | 新增；未认证周期不能给方向 |

## 候选因子检查

开发集使用8只A股且只使用2022年底以前数据；第一次留出集使用4只不同A股且只使用2023年以后数据。20日短期均值回归的结果为：

| 数据 | 原信号IC | 融合后IC | 原方向命中 | 融合后方向命中 |
| --- | ---: | ---: | ---: | ---: |
| 开发集 | 0.0055 | 0.0115 | 52.09% | 52.28% |
| 不同股票留出集 | 0.0179 | 0.0235 | 52.76% | 53.32% |

提升很小，因此该因子最多只能是辅助修正，不能单独形成方向。52周位置、量价确认和波动率方向分在不同期限或留出样本中变号，取消正式计分。

## 为什么最后仍撤销方向认证

随后使用不同股票和较晚日期进行滚动检验。每个历史日期T都重新截取此前五年数据；先保存当时信号，之后才读取未来结果。检验发现：

- 20日和60日信号在A股与美股之间明显不稳定；
- 120日可用的独立信号太少；
- 250日在五年窗口内更难形成足够独立样本；
- 5日信号在第一批股票约为60%的方向命中，但换第二批未使用股票后不能稳定复现；
- 收紧到“只有完整通过才可行动”后，最终新美股样本只有7次信号，命中42.86%，平均符号调整后超额收益为-0.83%；样本少且结果为负；
- 同轮新A股样本虽有32次信号、命中65.63%，但前一批新A股样本曾低于50%，批次间不稳定，不能据此认证。

所以`DIRECTION_CERTIFICATION`当前为空。以后恢复某市场某周期的认证，至少需要：

1. 预先固定因子、权重和阈值；
2. 开发样本与留出样本完全分开；
3. 至少两批不同股票与不同时间段方向一致；
4. 同时观察命中率、超额收益、覆盖率和回撤；
5. 失败后可以撤销认证，但不能用留出答案反复调参再把同一批数据称为留出集。

## 单次端到端历史时点测试

测试条件在运行前固定：

- 股票：JPM；
- 请求日期：2024-07-06；
- 自动采用交易日：2024-07-05；
- 用户目标：波段操作；
- 周期由Agent A自行选择，不人工指定。

Agent B只读取T及以前数据，得到：

- 自动周期：1—3个月（60个交易日）；
- 观察分：51/100；
- 风险：R3；
- 用户等级：C4；
- 方向验证：未通过；
- 结论：个人条件可讨论，但方向证据不足。

保存判断后，开发人员才在独立脚本中读取未来60个交易日：

- JPM收益：+2.96%；
- SPY收益：+3.76%；
- 超额收益：-0.80%；
- 区间内从阶段高点最大回撤：-10.13%。

该案例中模型没有强猜涨跌。股票虽上涨，但跑输基准且经历明显回撤，因此“方向证据不足”比强行给买入结论更符合证据。

## Agent A与B如何保持一致

- A的唯一核心逻辑位于根目录`agent_core.py`和`factor_analysis.py`；
- B不包含自己的`agent_core.py`；
- B运行时直接导入A，并记录`MODEL_VERSION`、`MODEL_RULESET_ID`和核心文件SHA-256；
- 自动测试会检查B没有私有模型副本；
- B不读取T之后行情，不计算未来收益，也不会根据回测结果自动改权重。

## 不能宣称的内容

- 不能说观察分是上涨概率；
- 不能说V6.6已经提高未来收益；
- 不能因为某一只股票回测正确就说模型有效；
- 不能把“拒绝判断”偷偷算成预测命中；
- 不能为了匹配已知行情修改B。

本版可准确表述为：V6.6降低了没有样本外证据支持的方向结论，并建立了可复现的因子审计和认证流程；它尚未证明具有稳定的未来涨跌预测能力。
